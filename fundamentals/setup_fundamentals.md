# Before We Get Into AI

Let's understand the basics and fundamentals of software development projects, along with the tools that make a developer's life easier.

## Developer Tools

| Tool | Use Case | Official Documentation | My Documentation |
|---|---|---|---|
| [uv](https://github.com/astral-sh/uv) | An all-in-one Python project and package manager. Handles Python versions, virtual environments, dependency management, and package installation. | [Official uv Docs](https://docs.astral.sh/uv/) | [My uv Notes](./documentations/UV.md) |
| [Ruff](https://github.com/astral-sh/ruff) | A fast Python linter and formatter. Identifies *code quality issues*, unused imports, undefined variables, and formatting inconsistencies. | [Official Ruff Docs](https://docs.astral.sh/ruff/) | |
| [Pyright](https://github.com/microsoft/pyright) | A static type checker for Python. Identifies type mismatches, incorrect function arguments, and potential type-related errors without executing the application. | [Official Pyright Docs](https://microsoft.github.io/pyright/) | |
| [pytest-cov](https://github.com/pytest-dev/pytest-cov) | A Pytest plugin that measures test coverage and identifies which parts of the application are not covered by automated tests. | [Official pytest-cov Docs](https://pytest-cov.readthedocs.io/) | |
| [Bandit](https://github.com/PyCQA/bandit) | A Python security analysis tool that identifies potentially insecure coding patterns and common security issues. | [Official Bandit Docs](https://bandit.readthedocs.io/) | |
| [pre-commit](https://github.com/pre-commit/pre-commit) | A framework that automatically runs linting, formatting, and validation checks before Git commits. | [Official pre-commit Docs](https://pre-commit.com/) | |
| [tox](https://github.com/tox-dev/tox) | Automates testing across multiple Python versions and environments to verify application compatibility. | [Official tox Docs](https://tox.wiki/) | |
| [Sphinx](https://github.com/sphinx-doc/sphinx) | A documentation generator that creates structured technical documentation from Python docstrings and reStructuredText or Markdown files. | [Official Sphinx Docs](https://www.sphinx-doc.org/) | |
